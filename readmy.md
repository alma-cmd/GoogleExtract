# 📸 Google Takeout Organizer

Программа для извлечения фото и видео из архивов Google Takeout с автоматической
сортировкой по годам и месяцам и восстановлением метаданных (EXIF) из JSON-файлов Google.

## ✨ Возможности

- **Три режима источника:** один ZIP-архив, папка с несколькими ZIP-архивами, уже распакованная папка.
- **Сортировка по дате съёмки:** файлы раскладываются в структуру `Год/Месяц` (например, `2019/07`).
- **Восстановление EXIF (JPEG):** дата съёмки, описание и GPS-координаты записываются прямо в файл из JSON Google.
- **Системные даты для всех файлов:** для видео и HEIC устанавливается дата создания/изменения файла — её читают галереи, Plex и проводник.
- **Папка `Unsorted`:** файлы с подозрительной датой (текущий месяц или будущее) складываются отдельно, чтобы не засорять хронологию.
- **Защита от дубликатов:** одноимённые файлы не перезаписываются, а получают суффиксы `_1`, `_2`, ...
- **Графический интерфейс:** выбор папок, прогресс-бар, подробный лог, опции обработки.
- **Безопасность данных:** битые JSON не приводят к потере файла — дата берётся из файловой системы с пометкой в логе.

## 🚀 Установка и запуск

### Требования

- Python 3.10 или новее
- Свободное место на диске: **примерно двойной размер архивов** (на время распаковки)

### Установка зависимостей

В терминале PyCharm (`Alt+F12`), находясь в папке проекта:

```bash
pip install -r requirements.txt
```

или, если вы используете `uv`:

```bash
uv pip install piexif
```

### Запуск

Правый клик по `main.py` в PyCharm → **Run 'main'**, либо из терминала:

```bash
python main.py
```

## 🖥️ Интерфейс

| Элемент | Назначение |
|---|---|
| **Источник** | Папка с ZIP-архивами Takeout, один ZIP или распакованная папка |
| **Куда сохранить** | Папка, в которой будет создана структура `Год/Месяц` |
| ☑ **Удалить временные файлы после обработки** | Удаляет папку распаковки `temp_takeout_extract` по завершении. Снимите галочку, чтобы изучить распакованную структуру и JSON проблемных файлов |
| ☑ **Файлы с датой за текущий месяц или из будущего складывать в папку Unsorted** | Защита от «мусорных» дат (см. ниже) |
| **▶ Начать обработку** | Запуск обработки в фоновом потоке (окно не зависает) |
| **Прогресс-бар и лог** | Ход обработки и подробная информация по каждому файлу |

## ⚙️ Как это работает

### Порядок обработки

1. **Определение типа источника:** ZIP-файл / папка с ZIP / распакованная папка.
2. **Распаковка** всех архивов во временную папку `temp_takeout_extract` (путь выводится в лог).
3. **Поиск медиафайлов** по расширениям: `.jpg .jpeg .png .heic .heif .mp4 .mov .avi .mkv .webm .3gp`.
4. **Для каждого файла:**
   - поиск соседнего JSON (`file.jpg.json`, с учётом дубликатов `(1)` и нестандартной структуры);
   - извлечение даты съёмки и геоданных;
   - перемещение в `Год/Месяц` или `Unsorted`;
   - установка системных дат файла на дату съёмки;
   - запись EXIF (только для JPEG);
   - удаление использованного JSON.
5. **Статистика и очистка** временных файлов (если включена опция).

### Приоритет источников даты

| Приоритет | Поле JSON | Значение |
|---|---|---|
| 1 | `photoTakenTime` | Реальная дата съёмки (лучший вариант) |
| 2 | `creationTime` | Время создания/загрузки в Google |
| 3 | `modificationTime` | Время последнего изменения |
| 4 | дата модификации файла | Аварийный вариант (fallback), помечается в логе |

### Правило папки `Unsorted`

Дата съёмки не может быть из будущего или из текущего месяца, если телефон ещё не
синхронизирован с Google Фото. Поэтому любой файл с датой **>= первого числа текущего
месяца** считается подозрительным и помещается в папку `Unsorted` для ручной проверки.
Правило автоматическое: в декабре «подозрительным» станет декабрь и т. д.
После синхронизации телефона галочку можно снять.

### Записываемые EXIF-теги (JPEG)

| Тег | Содержимое |
|---|---|
| `DateTime`, `DateTimeOriginal`, `DateTimeDigitized` | Дата и время съёмки |
| `ImageDescription` | Описание из Google Фото |
| `GPSLatitude` / `GPSLatitudeRef` | Широта (N/S) |
| `GPSLongitude` / `GPSLongitudeRef` | Долгота (E/W) |
| `GPSAltitude` / `GPSAltitudeRef` | Высота над уровнем моря |

## ⚠️ Ограничения

- **EXIF вшивается только в JPEG.** Встраивание метаданных внутрь видео (MP4/MOV) и HEIC
  на чистом Python ненадёжно и может повредить файл, поэтому для них корректно
  выставляется системная дата файла — этого достаточно для хронологии в галереях.
- **Часовые пояса:** метки времени Google (Unix timestamp) конвертируются в локальное
  время компьютера, на котором запущен скрипт.
- Обработка больших архивов (десятки тысяч файлов) может занять от нескольких минут до часа.

## 🔧 Настройка (константы в `organizer.py`)

| Константа | Значение по умолчанию | Назначение |
|---|---|---|
| `MEDIA_EXTENSIONS` | jpg, png, mp4, mov и др. | Какие файлы считать медиа |
| `DEBUG_LOG_LIMIT` | `15` | Сколько первых файлов показать в логе подробно |
| `UNSORTED_FOLDER` | `"Unsorted"` | Имя папки для подозрительных дат |

## 🩺 Устранение неполадок

| Проблема | Причина | Решение |
|---|---|---|
| `ModuleNotFoundError: No module named 'piexif'` | Библиотека не установлена в виртуальное окружение | `uv pip install piexif` или `pip install -r requirements.txt` |
| «Найдено файлов: 0» | Выбрана папка с ZIP-архивами, а не распакованная папка (старая версия скрипта) | Обновите `organizer.py` до версии с поддержкой папок архивов |
| Старые фото попали в текущий месяц | У файлов нет даты в JSON — взята дата распаковки архива | Включена опция Unsorted; уже обработанные папки переместите вручную |
| Файлы с суффиксами `_1`, `_2` | Повторный запуск поверх старых результатов | Очистите папку назначения перед повторной обработкой |
| Окно «не отвечает» при старте | Идёт распаковка больших архивов, лог ещё не обновился | Дождитесь появления строк распаковки в логе |

## 💡 Рекомендации

- Перед повторной обработкой **очищайте папку назначения** или указывайте новую — иначе сработает защита от дубликатов.
- Для диагностики странных файлов **снимите галочку удаления временных файлов** и изучите их JSON в папке `temp_takeout_extract`.
- Не закрывайте окно программы до появления строки «✅ Готово!» в логе.
